# Heart-Attack-Prediction
Heart Attack Prediction Using Machine Learning Models is a project that uses machine learning algorithms to predict the risk of a heart attack based on health-related data such as age, blood pressure, cholesterol levels, heart rate, and other medical factors. Different ML models, such as Logistic Regression, Naive Bayes, Decision Tree, Random Forest, Support Vector Machine (SVM), Extreme Gradient Boost and K-Nearest Neighbors (KNN), are trained and evaluated to compare their performance and prediction accuracy. The goal is to identify potential heart attack risks early and support timely medical intervention.
